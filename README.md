# 🤖 AI Resume Analyzer

An AI-powered resume analysis and optimization tool built with **Python and Streamlit**. It analyzes resumes, evaluates ATS compatibility, compares resumes with job descriptions, provides NLP-based insights, and generates professional resume reports.

## ✨ Features

* 📄 **PDF Resume Upload & Text Extraction**
* 📊 **ATS Resume Scoring**
* 🎯 **Job Description Matching**
* 🧠 **NLP-Based Resume Analysis**
* 🛠️ **Technical Skills Detection**
* 🔍 **Missing Skills Identification**
* 📌 **Resume Section Detection**
* ⚡ **Action Verb & Weak Phrase Analysis**
* 📈 **Keyword Coverage & Keyword Density**
* 📋 **Bullet Point Detection**
* 📖 **Readability Analysis**
* 📊 **Visual Analysis Charts**
* 📑 **Professional PDF Analysis Report**
* ✨ **AI Resume Improvement Suggestions**
* 📝 **Field-Specific Resume Generator**
* 🎨 **Multiple Professional Resume Templates**
* 🌙 **Dark & Light UI Themes**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Pulkit-Nanda/AI-Resume-Analyzer.git
cd AI-Resume-Analyzer
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
